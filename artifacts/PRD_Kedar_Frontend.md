# PRD: Frontend & UI/UX (Kedar)

## Overview
Your goal is to make the platform look like a massive, state-of-the-art government system (think India Stack, UPI, or GeM scale). You are responsible for the "Wow Factor" during the pitch.

## Core Features to Implement

### 1. DPIIT & DigiLocker Verification UI
**Problem:** Startups need to prove their legitimacy instantly.
**Solution:**
*   On the Startup Dashboard (or Profile page), add a "Link DPIIT Certificate" section.
*   The user enters a mock number. Show a loading spinner, then a highly satisfying green checkmark and a `[✓ DPIIT Verified]` badge.
*   **Hackathon Wow Factor:** When a pilot is successfully completed, add a button: "Export Success Certificate to DigiLocker". Show a slick animation of a certificate being minted. This solves the "Startups need government reference letters" problem.

### 2. Officer Templates Library & Analytics Dashboard
**Problem:** The problem statement explicitly asks for "standard templates for problem statements... risk management".
**Solution:**
*   Create a new route: `app/(app)/templates/page.tsx`.
*   Design a beautiful "Resource Center" where officers can download standardized Word/PDF templates. (You don't need real files, just make the UI look like a professional document library).
*   **The Landing Dashboard:** When the officer logs in, don't just show them the Kanban board. Show them a massive Analytics Dashboard first. 
    *   Use `recharts` to show: "Total Pilot Funds Disbursed (₹)", "Startups Onboarded", "Success Rate (%)".
    *   This proves the platform is built for *scale*.

### 3. The Dynamic Contract Viewer
**Problem:** Siddharth is generating a dynamic AI contract in the backend, but the officer needs to read and sign it.
**Solution:**
*   On the Kanban board, under the "Pilot Active" column, upgrade the `ContractGenerator` button.
*   When clicked, it should open a large, professional-looking Modal (like DocuSign).
*   Display the Markdown contract generated by Siddharth's backend.
*   Highlight the **Custom AI Injected Clauses** (e.g., Data Privacy) in a different color so the judges can clearly see that the contract is intelligent, not just a static template.
*   Add a "Digitally Sign & Approve" button at the bottom.

## Tech Stack
*   Next.js App Router (React)
*   Tailwind CSS (Prioritize clean, modern, slightly bureaucratic but sleek design — think deep blues, crisp whites, and distinct status badges).
*   Lucide Icons & shadcn/ui components
*   Recharts (for the Officer Dashboard)

## Implementation Steps
1.  Build the DPIIT Link UI on the startup side.
2.  Build the `app/(app)/templates` page and the Officer Analytics Dashboard.
3.  Coordinate with Siddharth: Once his `/api/proposals/[id]/contract` route is ready, build the beautiful DocuSign-style modal to display it.
